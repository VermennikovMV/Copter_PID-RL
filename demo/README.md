# Демонстрации

Три дрона в одной сцене Gazebo, одновременно и в одном и том же ветре:

| Дрон | Цвет | Висение | Трасса | Управление |
|---|---|---|---|---|
| drone1 | синий | слева | верхний (+4 м) | штатный ArduPilot (GUIDED) |
| drone2 | оранжевый | в центре | средний (+2 м) | ArduPilot + компенсатор возмущений (`RESID_ENABLE=1`) |
| drone3 | фиолетовый | справа | нижний | end-to-end нейросеть (команды моторам) |

На трассе все трое летят один и тот же квадрат, один над другим через 2 м, — сразу видно, кто впереди.

```bash
python demo/run.py race      # трасса 10×10 м с остановкой, без помех: кто быстрее
python demo/run.py payload   # висение, у всех одновременно отцепляется груз 0,35 кг (20 % массы)
python demo/run.py wind      # висение в сильном порывистом ветре: спереди, затем разворот направо
python demo/run.py final     # трасса с остановкой, сбросом груза в полёте и порывами ветра
```

По умолчанию открывается окно Gazebo. `--record demo_wind.mp4` вместо окна снимает видео камерой
сцены (в темпе симуляции, с подписями дронов, таймером, скоростью ветра, отклонением от
точки при висении и временем финиша на трассе).

Что показали записи (одна попытка каждой сцены, Gazebo + SITL):

| Сцена | ArduPilot | Компенсатор | End-to-end |
|---|---|---|---|
| Ветер: среднее отклонение | 22,7 см | **9,9 см** | 15,3 см |
| Сброс груза: наибольшее отклонение | 6,5 см | 4,5 см | **3,8 см** |
| Трасса: финиш | 21,2 с | 21,2 с | **18,3 с** |
| Трасса с грузом и ветром: финиш | 21,3 с | 21,1 с | **19,5 с** |

Ветер. Gazebo уже считает сопротивление воздуха Iris при движении относительно земли
(≈ 1,52 Н на м/с), поэтому добавочная сила 1,52·w(t) даёт сопротивление относительно воздуха,
движущегося со скоростью ветра w(t). Профиль w(t): средний ветер + турбулентность (случайные
колебания ~20 % с характерным временем ~2 с, направление ±8°) + порывы формы «1 − cos», с плавным
нарастанием. В сцене ветер показывают светлые штрихи, летящие с его скоростью.

Нужны: собранный [ardupilot-ROSMeetUp](https://github.com/VermennikovMV/ardupilot-ROSMeetUp),
Gazebo Harmonic с `ardupilot_gazebo` и плагин возмущений (см. [docs/setup.md](../docs/setup.md)).
