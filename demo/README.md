# Демонстрации

Три дрона в одной сцене Gazebo, одновременно и в одном и том же ветре:

| Дрон | Цвет | Управление |
|---|---|---|
| drone1 | синий | штатный ArduPilot (GUIDED) |
| drone2 | оранжевый | ArduPilot + компенсатор возмущений (`RESID_ENABLE=1`) |
| drone3 | фиолетовый | end-to-end нейросеть (команды моторам) |

При висении дроны стоят рядом. На трассе все трое летят одну и ту же трассу один над другим
(через 2 м: ArduPilot сверху, end-to-end снизу), поэтому сразу видно, кто впереди.

```bash
python demo/run.py race      # трасса: 8 пролётных точек, остановка на 2 с под конец, финиш
python demo/run.py payload   # висение, у всех одновременно отцепляется груз 50 % массы (0,88 кг)
python demo/run.py wind      # висение в сильном ветре: спереди, затишье, справа, затишье
python demo/run.py final     # та же трасса в боковых порывах ветра, в полёте сбрасывается груз 30 % массы
```

По умолчанию открывается окно Gazebo. `--record demo_wind.mp4` вместо окна снимает видео камерой
сцены (в темпе симуляции, с подписями дронов, таймером, скоростью и направлением ветра,
отклонением от точки при висении и временем финиша на трассе).

Что показали записи (одна попытка каждой сцены, Gazebo + SITL):

| Сцена | ArduPilot | Компенсатор | End-to-end |
|---|---|---|---|
| Ветер: среднее отклонение | 20,8 см | **9,3 см** | 12,8 см |
| Груз 50 %: наибольшее отклонение | 17,5 см | 13,5 см | **8,8 см** |
| Трасса: финиш | 36,3 с | 36,3 с | **27,0 с** |
| Трасса в ветре с грузом 30 %: финиш | 42,5 с | 36,6 с | **29,9 с** |

- На трассе ArduPilot притормаживает у каждой пролётной точки: в GUIDED он получает точку как
  «долететь и зависнуть», и его планировщик заранее строит торможение. End-to-end видит
  следующую точку и пролетает её на скорости. Компенсатор планировщик не меняет; в ветре он
  быстрее штатного ArduPilot, потому что тот дольше не может войти в радиус точки.
- Груз 50 % больше, чем был в обучении (масса до +30 %, сброс до 20 %). При висении его
  удерживают все трое. В пробе финала с грузом 50 %, отцепившимся в резком повороте под
  боковым порывом, end-to-end потерял управление, а ArduPilot и компенсатор долетели: у сети без
  каскада нет гарантий вне условий обучения.

Ветер. Gazebo уже считает сопротивление воздуха Iris при движении относительно земли
(≈ 1,52 Н на м/с), поэтому добавочная сила 1,52·w(t) даёт сопротивление относительно воздуха,
движущегося со скоростью ветра w(t). Каждый порыв ветра: средний ветер + турбулентность (случайные
колебания ~20 % с характерным временем ~2 с, направление в пределах нескольких градусов) + порыв
формы «1 − cos», с плавным нарастанием и спадом. В сцене ветер показывают светлые штрихи, летящие
с его скоростью.

Нужны: собранный [ardupilot-ROSMeetUp](https://github.com/VermennikovMV/ardupilot-ROSMeetUp),
Gazebo Harmonic с `ardupilot_gazebo` и плагин возмущений (см. [docs/setup.md](../docs/setup.md)).
