# Результаты

Все сравнения — на одинаковых сценариях и seed (90000–90007 для порывов): расписание
возмущений, начальное состояние и трасса совпадают у всех регуляторов.

Метрики:
- **RMSE / пик** — среднеквадратичное и максимальное расстояние до точки при висении
  (первые 2 с пропускаются);
- **скачок груза** — максимальное отклонение высоты за 3 с после сброса;
- **уход с линии** — расстояние до отрезка между точками трассы (RMS и максимум);
- **время трассы** — до засчитывания финиша (0,5 с в радиусе 0,4 м).

## Gazebo + SITL

Прошивка [ardupilot-ROSMeetUp](https://github.com/VermennikovMV/ardupilot-ROSMeetUp):
одна сборка, компенсатор включается параметром `RESID_ENABLE`. End-to-end управляет моторами
через перехват PWM (ArduPilot только взлетает и выводит аппарат в точку старта), шаги
синхронные по 20 мс. End-to-end обучен с более широкой рандомизацией, чем компенсатор
(моторы ±15 %, задержки до 40 мс, шумы ×2).

### Повышенная скорость ArduPilot (WP_SPD = 6 м/с)

| Трасса | ArduPilot 3 м/с | ArduPilot 6 м/с | Компенсатор 6 м/с |
|---|---|---|---|
| Время | 21,4 с | 18,9 с | 18,7 с |
| Порывы: уход с линии RMS | 14,3 см | 21,9 см | 20,9 см (−5 %) |
| Порывы + груз: уход RMS / скачок высоты | 14,7 / 9,5 см | 22,2 / 8,2 см | 21,0 / 7,2 см (−6 % / −12 %) |
| Пиковый наклон | 29° | 30° | 33° |

На 6 м/с ArduPilot упирается в предел наклона `ATC_ANGLE_MAX` = 30°: отклонения определяются
пределом манёвра, а не возмущениями, и выигрыш компенсатора мал. End-to-end (18,3 с) быстрее
ArduPilot и на 6 м/с.

| Опыт | Величина | SITL | Копия | Расхождение |

| | RMS / пик отклонения | 11,4 / 47,5 см | 12,2 / 45,9 см | +7 % / −3,5 % |
| Трасса AUTO | время | 25,97 с | 25,93 с | −0,2 % |
| | RMS / пик отклонения | 9,6 / 47,2 см | 10,9 / 46,4 см | +13 % / −1,6 % |
| Сила 3 Н на 2 с | пик / откат | 20,0 / −12,7 см | 22,0 / −14,8 см | +10 % / −16 % |
| Порывы | пик / RMS | 24,0 / 14,0 см | 25,8 / 14,0 см | +8 % / 0 % |
| Груз | просадка / скачок | 7,5 / 6,5 см | 7,4 / 7,5 см | −1 % / +15 % |

До сверки исходная копия расходилась с ArduPilot на +54…+157 % по возмущениям: не было
формирователя цели GUIDED, контура ускорения по высоте, модели ориентации и сопротивления
воздуха. Выигрыш, измеренный против такой копии, в Gazebo не подтвердился бы.
