# Воспроизведение v24: точные границы

Малой самодостаточной v24 training capsule в пакете нет. Прямая source-freeze
содержит165 файлов27,0МБ. Официальный bound plan содержит565 дополнительных
immutable entries с повторяющимися путями; их сумма275486723 байта не равна
уникальному размеру. После дедупликации и добавления наблюдённых source guards
конкретный кандидат содержит420 файлов252397863 байта, включая232 trace/IO
файла233842702 байта. Они нужны для прежних контролей и доказательств;
одних названий и SHA недостаточно для повторного выполнения этих guards.

[Точный allowlist зависимостей](../evidence/research_evidence_dependency_manifest_v24_candidate.json)
сохраняет относительные пути, исходные SHA и размеры без копирования тяжёлых
трасс. Исследовательские файлы и проверяющие функции не изменялись. Нельзя
подменять `sha()`, выдавать digest исходника за hash projected bytes, удалять
обязательные bindings или считать отсутствие данных подтверждённой проверкой.

Отдельный Release asset пока [только предложен](research_evidence_release.md),
архив не создавался. Stdlib helper проверяет и восстанавливает exact bytes;
после будущего восстановления нужны отдельные imports/source-guards/preflight
проверки. До них работоспособность восстановленного обучения не заявляется.

Для нынешнего строгого запуска нужен полный исходный workspace с exact данными и
Python/Torch/SB3/PyBullet окружением. Из его корня оригинальная
`train_joint_initial24.cmd --prepare-only` проверяет новый план без main;
`train_joint_initial24.cmd` запускает новое дообучение через official preflight
с fresh output. Это команды полного workspace, не малого чистого клона.
[Исходники команд](../source_archive/recording_latest/README.md) явно помечены
WORKSPACE_ONLY. Пробные веса не становятся initializer. Новый запуск и его
выходные веса не наследуют качество какой-либо архивной Gazebo-таблицы.

Самостоятельный перенос требовал бы полной проверяемой копии closure либо
отдельного проспективного плана регенерации недостающих доказательств с реальными
измерениями. Такой запуск при подготовке пакета не выполнялся. Историческая
guarded v8 capsule остаётся отдельной проверенной возможностью; она не
воспроизводит v24. Portable v20 CPU inference проверен отдельно по архивным
наблюдениям и не требует полного training workspace.
