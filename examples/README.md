# Сохранённые состояния и настоящие команды

```bash
python scripts/replay_controllers.py --controller all
```

| Пример | Происхождение | Проверка |
|---|---|---|
| [Direct111](direct111_hover1500.provenance.json) | Все 1500 отсчётов исторического быстрого физического стенда Direct FAST, strong hover | Полный state→observation→action, собственная предыдущая команда |
| [Текущий гибрид v29](phase29_route2000.provenance.json) | Все 2000 отсчётов причинного PyBullet маршрута nominal84001 | Общий кодировщик, valid-leg gate, выбранный эксперт, переход к маршруту и финальное удержание |

Сохранены реальные time/dt, позиция, скорость, ориентация, body rates, текущая цель,
предыдущая команда и записанные выходы. Воспроизведение последовательно вызывает
`predict_enu`, а не подставляет заранее выбранного эксперта. Итог: 3500 вызовов
сетей, все ошибки равны нулю; 43 отсчёта F0 и 1957 маршрутного эксперта.
Direct-пример не является Gazebo-записью; v29-пример не новая физическая реплика.

Дополнительно `python scripts/replay_memory20_example.py` проверяет 64 уже
закодированных наблюдения F0 из Gazebo83301/force_strong/route: исходные окна
0..31 и 236..267. Это отдельная проверка conditioning, не непрерывная история
кодировщика. [Происхождение](memory20_encoded_obs64.provenance.json).

Нужен NumPy, не Torch/PyBullet/Gazebo. Ни одна команда replay не запускает новую
симуляцию или обучение и не доказывает качество вне измеренной области карты.
