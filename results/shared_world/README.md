# Три контроллера в одном мире Gazebo

Два записанных опыта: маршрут при постоянной внешней силе и удержание при трёх порывах. **Один запуск каждого сценария, seed 83301**. Это демонстрационные сравнения выбранных моделей; статистическая уверенность и преимущество в других условиях по ним не заявляются.

История и накопленный бюджет обучения Direct111 и Hybrid phase29 различаются.
У Hybrid два эксперта с общим encoder, из которых на каждом отсчёте выбирается
один. Здесь сравниваются конкретные готовые системы; превосходство архитектуры
при равном обучении не доказано. [Бюджеты и происхождение весов](../../docs/training_comparison.md).

| Условия | Значение для всех трёх дронов |
|---|---|
| Модель и масса | Iris, 1,75 кг; одинаковые инерция, моторы и столкновения |
| Дополнительный груз | Нет |
| Начало | Первая точка [0, 0, 3] в локальной системе каждой трассы; общий старт после стабилизации |
| Проверка старта | Ошибка ≤3 см, скорость ≤5 см/с непрерывно ≥1 с; фактически ошибка ≤5 мм |
| Трасса | [0,0,3] → [2,0,3] → [2,2,3.5] → [0,2,3] → [0,0,3] |
| Подтверждение точки | Радиус 25 см и удержание 0,5 с; реальные пропуски измерений прерывают выдержку |
| Расстановка | Одинаковые трассы со смещением 4 м по X |
| Ветер | Внешняя сила 2,856 Н; одинаковый вектор прикладывается всем в один такт физики |
| Контроллеры | Замороженный PID, Hybrid phase29, Direct111; нового обучения для этих видео не было |

## Маршрут

| Метрика | PID | Hybrid | End-to-end |
|---|---:|---:|---:|
| Время прохождения, с ↓ | 9,460 | **8,399** | 11,298 |
| RMSE до активного конечного 3D-отрезка, м ↓ | 0,1442 | **0,0893** | 0,2126 |
| Пик отклонения от отрезка, м ↓ | 0,3423 | **0,2185** | 0,3702 |
| RMSE до текущей цели за весь опыт, м ↓ | 0,6585 | **0,5698** | 0,5898 |
| Максимальный недобор заданной высоты, м ↓ | **0,495** | 0,545 | 0,515 |
| RMSE курса, градусы ↓ | **0,3817** | 0,7572 | 0,8462 |
| Достигнутые точки | 5/5 | 5/5 | 5/5 |
| Отказы | 0/1 | 0/1 | 0/1 |

Hybrid в этом запуске быстрее PID на 11,2% и точнее по активному отрезку на 38,0%. PID лучше удерживает курс. Недобор высоты включает мгновенное повышение цели на 0,5 м в третьей точке: это не измерение свободного падения.

Горизонт опыта — 40 с. Сила [2,613; −1,152; 0] Н действовала с 4,933 до 20,234 с общего времени. Каждый контроллер получил 2000 команд без пропусков. После завершения маршрута все удерживали конечную точку до общего конца опыта; это удержание не входит в метрику активного отрезка.

Ветер включён по общим часам. Из-за разной скорости дроны проходят повороты в разное время — это сравнение всей миссии, а не отдельный опыт с включением ветра строго на каждом повороте.

Горизонт — 30 с. Порывы действовали в интервалах 4,939–7,904; 10,819–13,980; 16,882–20,237 с. Второй направлен противоположно первому, третий — перпендикулярно. У всех по 1499 команд из 1500 запланированных; один общий пропуск сохранён в журнале.

Hybrid снизил RMSE относительно PID на 48,1%, End-to-end — на 28,4%. Все оставались внутри допуска, поэтому сравнивать скорость восстановления после выхода из допуска здесь нельзя. Техническое значение 18 мс в JSON — первое подходящее измерение после отключения силы, затем проверяется ещё 1 с удержания; это не время адаптации.
