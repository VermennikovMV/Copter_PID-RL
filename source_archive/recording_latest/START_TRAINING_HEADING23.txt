V23 — реальные обучение B и настольный монитор для записи

Из PowerShell в полной папке проекта v2:
  .\show_joint_training_native_v23.cmd
Читается новое B:
  artifacts/refinement/joint_v2/route_heading_pilot_v23_111/zero_route_integral
A — явно архивный обученный P1 контроль: его обучение и original24 оценки
переиспользованы. Отдельные15 оценок A matched profiles выполнены до B main
без новых Adam updates. Они не называются новым обучением A.

Изменён один фактор: чередование route resets внутри каждого из16 env между
прежним случайным абсолютным yaw и измеренным yaw Gazebo. Смещение yaw reference
сохраняет исходную относительную ошибку курса. Это правило 50/50 по чередованию,
а не обещание ровно половины всех эпизодов или контрольного времени. Реальные
reset counts и control-секунды берутся из heading_counts_critic/ppo.json;
файлы снимков появляются после завершения соответствующей стадии.

Original24 native метрики и пять matched native профилей показаны раздельно.
Hard24 не равен Admit24; итог требует original24 admission И matched5 PASS.
Все действительные FAIL сохраняются. Source baseline0 — отдельная прежняя оценка
без нового PPO. Matched native профили не являются новыми полётами Gazebo.
Награда — ход процесса, не замена метрик или доказательство применимости.

Для новой собственной видеозаписи обучения только B:
  .\train_joint_heading23.cmd --prepare-only
После ROOT binding создаётся и проверяется свежий план без обучения. Пока точный
ROOT BOUND SHA не зафиксирован, launcher отказывает до создания output.
Настоящий запуск нового процесса:
  .\train_joint_heading23.cmd --run
Без флага команда также запускает новое B после preflight. Бюджет:131072critic+
262144PPO,3 checkpoints с original24+matched5 оценками. Все настройки и критерии
точного BOUND плана сохраняются; меняются только output/research-plan пути и
пояснение записи. A и законченный A Aux15 не запускаются повторно.

Начальные веса68dafd98 уже обучены: это дообучение в PyBullet, не с нуля и не
в Gazebo. Текущая проверенная демонстрационная модель не заменяется. Выданная
команда монитора указывает новый recording_heading23_<время>_<id> output:
  .\show_joint_training_native_v23.cmd -RunRoot <output из ответа подготовки>

Проверка чтения без окна:
  .\show_joint_training_native_v23.cmd -VerifyOnly
  .\show_joint_training_native_v23.cmd -PlanOnly
ERROR имеет приоритет над устаревшим heartbeat/validation; причина видна в статусе.
Архив A никогда не показывается как живое обучение. Видео окна включите сами.
HTTP, браузер и автоматическая запись не запускаются. Закрытие монитора не
останавливает обучение. Новая V23 не является проверенной моделью Gazebo до
отдельной реальной матрицы полётов.
