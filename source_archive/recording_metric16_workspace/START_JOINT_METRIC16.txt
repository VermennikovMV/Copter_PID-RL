Gazebo: последняя измеренная модель гибрида, metric_cost16 / Route80

Откройте PowerShell в полной папке проекта v2. Записывайте окно сами:

  .\show_joint_metric16.cmd
  .\show_joint_metric16.cmd -Controller pid

По умолчанию: сильная ветровая сила, маршрут, seed83301. Измерение40с;
после завершения маршрута продолжается удержание. Пять маркеров — текущие цели.
Нейросеть задаёт тягу/угловые скорости; нижний ПИД ArduCopter управляет моторами.

Другие одинаковые парные условия для RL/PID:
  .\show_joint_metric16.cmd -Scenario gust -Mission hover
  .\show_joint_metric16.cmd -Scenario nominal -Mission route
  .\show_joint_metric16.cmd -Scenario force_strong -Mission route -Seed 84001
К каждой команде добавьте -Controller pid для второго контроллера.

Это диагностическая модель68dafd98…; допуски без ветра и при отдельном попутном
ветре84001 не пройдены. В основной матрице7из8 условий проходят инженерные
допуски: это не означает7 побед над ПИД. Одна модель/один просмотренный случай
на условие,9 новых полётов+11 общих контролей; финальной независимой проверки нет.
Сила задана в ньютонах, не скоростью в м/с. Старые77 команды — другая модель.

Без запуска симуляции:
  .\show_joint_metric16.cmd -VerifyOnly
  .\show_joint_metric16.cmd -PlanOnly

Занятый Gazebo не прерывается. Каждый запуск сохраняет новую папку
artifacts/user_runs/..._metric16_... с измерениями, NN-командами и проверками.
Нового обучения, HTTP-сервера и автоматической видеозаписи здесь нет.
