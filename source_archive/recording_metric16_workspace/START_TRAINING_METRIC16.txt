Реальное повторное дообучение metric_cost16 для записи видео

В PowerShell из полной папки проекта v2:
  .\train_joint_metric16.cmd

Создаётся уникальная папка recording_metric16_<время>_<id>/metric_cost.
Исходный проверенный эксперимент и текущие демонстрационные веса не заменяются.
Запуск выполняет настоящий critic warmup131072, затем PPO262144 через официальный
preflight; настройки, семена, начальные веса и три checkpoint те же, что у v16.
Начальные веса уже обучены: это дообучение, а не обучение с нуля.
Обучение идёт в PyBullet. Gazebo используется отдельно для проверки, не для PPO.

Без запуска обучения:
  .\train_joint_metric16.cmd --prepare-only
Команда выдаст JSON с точными plan/output; физики и optimizer steps при этом0.

Для записи текущего состояния можно открыть phase.json и progress.csv из новой
папки metric_cost. Они содержат реальные стадии/счётчики; архивный файл не является
живым обучением. HTTP-сервер, браузер и отдельный монитор здесь не запускаются.
Новая демонстрационная модель не наследует качество исходной таблицы и не подменяет
модель команды show_joint_metric16.cmd автоматически.
